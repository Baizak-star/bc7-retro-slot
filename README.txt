BC7 v2 — black metal / gold slot machine redesign

This is a complete Flask project. The game uses virtual points only.

Run on macOS:
1. Open Terminal.
2. Move into this folder, for example:
   cd ~/Desktop/BC7_v2
3. Start Flask:
   python3 app.py
   If Flask is not installed in your active Python environment, install it with:
   python3 -m pip install flask
4. Open http://127.0.0.1:5000 in Safari.

The game server endpoint and payout rules remain in app.py. Balance resets to 1,000 when the page is refreshed.
